# Contributing to WorkTravel Academy Core

We welcome thoughtful contributions that help improve the learning platform model, contributor journey, and community experience.

## What to contribute

- academy structure improvements
- onboarding and learning flow guidance
- community and contributor experience enhancements
- documentation and design notes
- educational process refinements

## How to contribute

1. Read the repository purpose and project context.
2. Open an issue for larger suggestions or design discussions.
3. Submit a pull request with a clear summary and rationale.

## Expectations

- prioritize clarity and usability
- keep the academy model practical and learner-focused
- explain the value of the change in context
- maintain a contributor-friendly, open collaboration culture

## Review guidance

Changes should help make the learning experience clearer, more useful, and easier to participate in.
